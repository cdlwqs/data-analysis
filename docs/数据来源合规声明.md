# 数据来源合规声明

## 数据源
- **名称**：Olist Brazilian E-Commerce Public Dataset by Olist
- **URL**：https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- **发布方**：Olist（巴西电商平台），Kaggle 托管
- **License**：CC BY-NC-SA 4.0（署名-非商业性使用-相同方式共享）

## 获取方式（白名单，非爬虫）
1. **实际使用**：通过 Kaggle 官方页面下载按钮获取真实数据集压缩包，解压后获得 9 张 CSV 表，放入 `data/raw/` 目录。
2. **备选**：Kaggle 官方 CLI `kaggle datasets download -d olistbr/brazilian-ecommerce`（需 `~/.kaggle/kaggle.json` 凭证）。
3. **回退**：本机无 Kaggle 凭证时，`scripts/01_load.py` 使用 Faker 按 Olist 官方 Schema 生成结构一致、分布贴近真实的合成数据，每条记录标注 `is_synthetic=True`。

## 合规要点
- ✅ 仅通过 Kaggle 官方下载获取真实商业交易数据
- ✅ 不使用 Scrapy / Selenium / requests+网页解析 / 模拟登录等任何爬虫技术
- ✅ 数据为 Olist 官方公开发布，已匿名化处理
- ✅ 数据规模 99,441 订单 / 94,395 客户 / 32,945 产品 / 3,095 卖家 / 9 张表
