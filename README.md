# 纽约 Airbnb 民宿定价与房源特征可视化分析

> 《商业数据分析》期末大作业 · 2026 年秋季学期 · 嘉兴大学数据科学学院

## 一、项目简介

本项目以 **Inside Airbnb** 公开发布的纽约市 Airbnb 房源数据集为分析对象，使用 Python 技术栈（Pandas / NumPy / Matplotlib / Seaborn / Scikit-learn / Streamlit / python-docx）完成"数据获取 → 清洗治理 → 模型分析 → 图表复现与大屏呈现 → 商业洞察提炼"的端到端流程。应用 **K-Means 聚类、随机森林定价预测、RFM 房东价值分群、帕累托/ABC 分类、月度时序趋势** 五种商业分析模型，产出 19 张可视化图表与 1 个交互式大屏，并提炼可落地商业建议。

## 六、核心结论摘要

1. **K-Means 聚类**：19,203 房源划分为 4 簇（经济型 5,510 / 中端 1,507 / 精品 2,744 / 大容量 9,442），各簇价格、可住天数、评论数差异显著。
2. **随机森林定价预测**：R² = 0.63，RMSE = 160.36 USD，最重要特征为房型、行政区、可住天数、经度，模型解释力良好。
3. **RFM 房东价值**：8 分群中"重要价值"房东 2,210 人贡献最高金额，应优先运营维护。
4. **帕累托/ABC**：221 街区中 A 类 20 街区贡献 69.0% 房源量，符合 20/80 法则，A 类为核心区域。
5. **时序趋势**：150 个月评论数波动上升，近 24 月活跃房源持续增长，市场呈扩张态势。
