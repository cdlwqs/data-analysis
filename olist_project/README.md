# Olist电商用户价值与留存可视化分析

> 《商业数据分析》期末大作业 · 2026 年秋季学期 · 嘉兴大学数据科学学院

## 一、项目简介

本项目以 Kaggle 公开发布的 **Olist 巴西电商数据集** 为分析对象，使用 Python 技术栈（Pandas / Matplotlib / Seaborn / Pyecharts / Streamlit）完成"数据获取 → 清洗治理 → 模型分析 → 图表复现与大屏呈现 → 商业洞察提炼"的端到端流程。应用 **RFM 用户价值八分类、同期群留存分析、帕累托/ABC 分类、环比/同比+移动平均、SARIMA 预测** 五种商业分析模型，产出 19 张可视化图表与 1 个交互式大屏，并提炼可落地商业建议。

## 六、核心结论摘要

1. **RFM**：7,299 客户划分为 8 类，重要价值客户 1,377 人贡献 39.1% 销售额，应优先运营。
2. **同期群**：23 个群，第 3 月平均留存率 6.0%，复购健康度偏低，需加强复购激励。
3. **帕累托/ABC**：51 类中 A 类 17 类贡献 69.4% 销售额，符合 20/80 法则，A 类为核心品类。
4. **趋势**：23 个月销售额波动上升，最近月 94,420 BRL，3 月均线 85,839 BRL，呈增长态势。
5. **SARIMA 预测**：SARIMA(1,1,1)(1,0,1,12) 模型回测 MAPE=4.31%、RMSE=4,562，未来 6 月预测稳定在 85,500–85,700 BRL 区间。
